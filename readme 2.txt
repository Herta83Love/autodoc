# AutoDoc

AI-powered documentation generator for SENTRY.

## Features

- Menu Discovery
- Page Crawling
- Screenshot Capture
- HTML Export
- Metadata Extraction
- Azure OpenAI Vision Analysis
- Automated DOCX Manual Generation

## Architecture

Menu
↓
Crawler
↓
Screenshot
↓
Metadata
↓
GPT-4.1-mini Vision
↓
Structured JSON
↓
Word Manual
